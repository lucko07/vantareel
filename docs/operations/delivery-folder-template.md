# Delivery Folder Template

Use this structure for every client delivery package:

```text
ClientName/
  01-Raw-Input/
  02-Selected-Moments/
  03-Drafts/
  04-Final-Clips/
  05-Thumbnails/
  06-Notes-Revisions/
```

## Usage Notes
- Keep naming consistent by week or batch.
- Store revision requests and outcomes in `06-Notes-Revisions`.
- Archive completed monthly batches in dated subfolders.
