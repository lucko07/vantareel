# Clip Quality Standards

## Hook Strength
- First line must create immediate curiosity or relevance.

## Pacing
- Remove unnecessary pauses.
- Keep momentum through jump cuts and concise phrasing.

## Caption Quality
- Accurate transcript with intentional line breaks.
- Readable size on mobile without covering subject face.

## Brand Consistency
- Typography, color, and text emphasis match client style.

## Platform Readiness
- Export dimensions and file names match channel requirements.
