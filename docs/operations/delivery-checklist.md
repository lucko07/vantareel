# Delivery Checklist

## Pre-Delivery
- Source footage and brief confirmed.
- Clip count matches plan.
- Captions checked for typos and timing.
- Safe-zone review complete.
- File names follow standard convention.

## Delivery Package
- Drafts or finals placed in correct client folders.
- Notes document includes clip-level context.
- Revision window and deadlines stated clearly.

## Final Handoff
- Final exports uploaded.
- Client notified with concise delivery summary.
- Internal tracker marked complete.
