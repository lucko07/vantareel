# Quality Rubric

## Scoring Scale
- 1: Poor
- 2: Needs work
- 3: Acceptable
- 4: Strong
- 5: Excellent

## Criteria
- Hook strength
- Pacing and retention flow
- Caption readability and timing
- Visual clarity
- Brand feel and consistency
- Retention potential
- Export accuracy and file hygiene

## Pass Threshold
- Minimum average score: 4.0
- No criterion below 3
