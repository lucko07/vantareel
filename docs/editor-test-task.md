# Editor Test Task

## Assignment
- Source: one 30 to 60 minute long-form video.
- Deliver: 3 short-form clips (9:16).

## What Success Looks Like
- Strong hook within first 2 seconds.
- Tight pacing and clear payoff.
- Clean captions with consistent styling.

## Export Requirements
- 1080x1920 MP4 H.264.
- File naming per SOP conventions.

## Hook and Caption Expectations
- Hook options should feel natural and specific.
- Captions should prioritize readability and emphasis.

## Evaluation Criteria
- Hook strength
- Pacing
- Caption quality
- Visual polish
- Platform readiness
